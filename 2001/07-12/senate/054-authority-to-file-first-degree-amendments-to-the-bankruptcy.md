# AUTHORITY TO FILE FIRST-DEGREE AMENDMENTS TO THE BANKRUPTCY REFORM BILL

```
AUTHORITY TO FILE FIRST-DEGREE AMENDMENTS TO THE BANKRUPTCY REFORM BILL

substitute amendment to the Bankruptcy Reform Act.
```
