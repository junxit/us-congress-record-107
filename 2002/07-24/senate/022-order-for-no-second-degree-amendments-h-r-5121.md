# ORDER FOR NO SECOND-DEGREE AMENDMENTS--H.R. 5121

**Speaking:** Reid, Harry (R000146) [D-NV]

**Measures:** H.R. 5121

```
            ORDER FOR NO SECOND-DEGREE AMENDMENTS--H.R. 5121

  Mr. REID. Mr. President, I want to clarify that with respect to the 
agreement on the legislative branch appropriations bill, there are no 
second-degree amendments in order to the Durbin, Cochran, or Landrieu 
amendments. I ask unanimous consent that be the order.
  The PRESIDING OFFICER. Without objection, it is so ordered.
```
