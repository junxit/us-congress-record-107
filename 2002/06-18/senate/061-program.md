# PROGRAM

**Speaking:** Reid, Harry (R000146) [D-NV]

```
                                PROGRAM

  Mr. REID. Madam President, tomorrow we should get well into the 
Defense authorization bill. It is very important legislation. It is 
literally for the security of this country. I hope Senators who have 
amendments will come and offer them. We have, really, with a bill of 
this importance, limited time to complete it. I hope everyone will help 
us expedite passage. There is so much more we need to work on.
  Madam President, I suggest the absence of a quorum.
  The PRESIDING OFFICER. The clerk will call the roll.
  The legislative clerk proceeded to call the roll.
  Mr. REID. Madam President, I ask unanimous consent that the order for 
the quorum call be rescinded.
  The PRESIDING OFFICER. Without objection, it is so ordered.

                          ____________________
```
