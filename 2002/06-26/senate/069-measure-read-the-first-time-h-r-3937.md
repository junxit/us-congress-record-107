# MEASURE READ THE FIRST TIME--H.R. 3937

**Speaking:** Reid, Harry (R000146) [D-NV]

**Measures:** H.R. 3937

```
                 MEASURE READ THE FIRST TIME--H.R. 3937

  Mr. REID. Mr. President, it is my understanding that H.R. 3937 was 
received from the House. I ask for its first reading.
  The PRESIDING OFFICER. The clerk will read the bill for the first 
time.
  The legislative clerk read as follows:

       A bill (H.R. 3937) to revoke a Public Land Order with 
     respect to certain lands erroneously included in Cibola 
     National Wildlife Refuge, California.

  Mr. REID. Mr. President, I now ask for its second reading and object 
to that request on behalf of a number of my colleagues.
  The PRESIDING OFFICER. The bill will remain at the desk.
```
